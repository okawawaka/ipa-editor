操作説明 (OPERATING INSTRUCTIONS)

ショートカット (SHORTCUTS)

  • ? または Shift + / : 操作説明画面を開閉します。
  • Ctrl + Z (Mac: Cmd + Z) : 直前の入力を元に戻します (UNDO)。
  • Esc : 操作説明画面を閉じます。

入力方法 (INPUT)

  • 字母の入力：盤面のボタンをクリックすると、入力欄のカーソル位置に文字が挿入されます。
  • 補助記号：修飾する文字の直後に入力すると結合されます。
  • 二重調音・連結：結ぶ2文字の間に入力します（◌͡◌ または ◌‿◌）。
  • 声調バー：連続する声調バーは合字（折れ線トーンバー）として連結表示されます。
  • [ ] 精密表記 / / 音素表記：文字を選択した状態でボタンを押すと選択範囲が括弧で囲まれます。未選択時は入力欄全体を囲みます。
