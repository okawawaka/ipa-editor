# IPA入力 国際音声字母エディタ (International Phonetic Alphabet Editor)

現代的で合理的なスイス・スタイル（Swiss Typographic Style）による、オープンソースの**国際音声字母 (International Phonetic Alphabet: IPA)** 入力エディタです。  
言語学・音声学の講義や研究、論文執筆、辞書編纂、音声分析（Praat等との連携）、語学学習向けに最適化されています。

ブラウザさえあれば、外部ソフトウェアのインストール不要で即座に動作します。

🔗 **公開デモサイト**: [https://okawawaka.github.io/ipa-editor/](https://okawawaka.github.io/ipa-editor/)

---

## 🌟 主な機能と特徴

### 1. 全339字母・記号の完全収録
- **肺臓気流子音 (Pulmonic Consonants)**: 破裂、鼻音、ふるえ、はじき、摩擦、側面摩擦、接近、側面接近
- **非肺臓気流子音 (Non-Pulmonic Consonants)**: 吸着音 (Clicks)、入破音 (Implosives)、放出音 (Ejectives)
- **二重調音 (Double Articulation)**: 接近音、破裂音、鼻音
- **母音台形 (Vowel Trapezoid)**: 全28種の基本母音（舌の高さ・前後・円唇/非円唇）を高精細幾何学フレーム上にプロット
- **補助記号 (Diacritics)**: 音節性、子音解放、発声・声門状態、調音位置、同時調音、気流機構
- **超分節要素 & 声調 (Suprasegmentals & Tones)**: 強勢、長短、境界、五段階水平調、曲線声調、イントネーション

### 2. 五段階声調バー（Chao Tone Letters）の合字・連続折れ線グラフ描画
- 単音調バー `˥`（超高）〜 `˩`（超低）の入力はもちろん、連続する声調記号（例: `˥˦` 高下降、`˩˥` 上昇、`˦˥˦` 昇降等）を高精細ベクターSVGによる連結折れ線グラフ（Tone Ligatures）として自然に合成・表示します。

### 3. スイス・タイポグラフィと結合文字（Combining Diacritics）の安定性
- 公式フォント `Noto Sans` および `Noto Sans JP` を採用し、結合文字の表示ズレや文字化けを徹底排除。
- 補助記号をクリックすると、カーソル直前の基底文字と自動的に正しく結合します。

### 4. 快適な入力体験（Sticky Dock & ショートカット）
- スクロールしても入力欄とツールバーが画面最上部に常時固定（Sticky Dock）。
- **ワンクリックコピー**: `COPY` ボタンでクリップボードへ即時コピー。
- **履歴管理**: 直前の入力を取り消す `UNDO` 機能。
- **ホバーティッカー**: 字母にカーソルを合わせると、正式名称・英語名・調音分類がリアルタイム表示。
- **キーボードショートカット**: `?` または `Shift` + `/` でヘルプモーダルを開閉。

## 📖 使い方（エンドユーザー向け）

1. **文字の入力**:
   - 表内の字母ボタンをクリックすると、上部のテキストエリアに文字が挿入されます。
2. **補助記号の結合**:
   - 先に基底となる字母（母音や子音）を入力し、その直後に補助記号ボタンをクリックすると、自動的に結合文字として合成されます。
3. **コピー & 活用**:
   - `COPY` ボタンを押すだけでクリップボードにコピーされます。そのまま Word、LaTeX、Praat、論文エディタ等にペーストして利用できます。
4. **検索・詳細確認**:
   - 記号の意味や名称がわからないときは、マウスカーソルを合わせると画面下部のステータスバーに日本語名・英語名・調音位置が表示されます。

## 🛠️ 開発者向けガイド (Developer Guide)

本プロジェクトは **Pure HTML / CSS / JavaScript (Vanilla JS)** で実装されており、ビルドツール（Webpack, Vite等）や外部ライブラリへの依存はありません。

### ディレクトリ構成

```text
ipa-editor/
├── index.html            # メインHTML（UI構造、メタタグ、OGP設定）
├── style.css             # スイス・スタイルCSS（グリッド、レスポンシブ、固定ヘッダー）
├── app.js                # アプリケーションロジック（入力処理、合字レンダリング、イベント制御）
├── data.js               # IPA全339記号のメタデータ辞書（名称・英語名・分類）
├── favicon.svg           # ベクターファビコン
├── favicon.png           # 32x32 ファビコン
├── apple-touch-icon.png  # 180x180 アプリアイコン
├── og-image.png          # 1200x630 OGPプレビュー画像
├── README.md             # 本ドキュメント
├── CHECKLIST.md          # 全機能の検証チェックリスト & 仕様書
├── LICENSE               # MITライセンス
└── .gitignore            # Git除外設定
```

### ローカルでの実行

ビルドステップは不要です。以下のいずれかの方法で即座に動作確認できます：

1. **直接開く**:
   `index.html` をお使いのブラウザ（Chrome, Firefox, Safari, Edge）で直接ダブルクリックして開く。
2. **ローカルサーバーで起動（推奨）**:
   ```bash
   # Python を使用する場合
   python -m http.server 8000

   # Node.js (npx) を使用する場合
   npx serve .
   ```
   ブラウザで `http://localhost:8000` を開きます。

### データの拡張・カスタマイズ (`data.js`)
記号の名称や調音説明は `data.js` 内の `IPA_DATA` オブジェクトで一元管理されています。
記号を追加または修正する場合は、`data.js` に対応するキーとプロパティを追加し、`index.html` に `data-ipa="記号"` 属性を持つボタンを配置してください。

```javascript
"記号": {
  name: "日本語名称",
  en: "English Name",
  type: "分類カテゴリ"
}
```
